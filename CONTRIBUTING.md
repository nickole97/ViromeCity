# Contributing to Virome City

Short version: the book is a [Quarto](https://quarto.org) project. Prose lives in
`.qmd` files, the navigation lives in `_quarto.yml`, and all styling lives in one
stylesheet.

## Setup

1. [Install Quarto](https://quarto.org/docs/get-started/).
2. Clone this repo.
3. Run `quarto preview` — it opens the book in a browser and reloads as you edit.

## Where things live

| I want to...                  | Edit this                          |
|-------------------------------|------------------------------------|
| Fix a typo, rewrite a section | `sections/<chapter>.qmd`           |
| Add a new chapter             | `_quarto.yml` — one line           |
| Change a colour, font, spacing| `assets/styles.scss` — the only place |
| Add an image                  | `assets/img/`, then reference it   |
| Change the wizard             | `kitchen/` (plain HTML, not Quarto)|
| Change a heatmap              | `components/` (plain HTML)         |

**Never edit anything inside `docs/`.** That folder is generated by
`quarto render`. Any change you make there will be erased on the next build.

## Adding a chapter

1. Create `sections/my-chapter.qmd` with a title in the front matter.
2. Add one line under `chapters:` in `_quarto.yml`.
3. Run `quarto preview`. The sidebar, the search index and the previous/next
   links all update on their own — there is no navigation to maintain by hand.

## House rules

**One stylesheet.** No inline `style="..."`, no `<style>` blocks inside chapters.
If you need a new visual pattern, add a class to `assets/styles.scss` so the rest
of the book can use it too.

**Images are files.** Never paste base64 image data into a chapter or into the
stylesheet — it makes the file unreadable and unsearchable.

**Colours come from the tokens.** Use the CSS variables defined at the top of the
stylesheet, never a raw hex value. The palette has two layers, and they don't mix:

- *Page layer* (`--ink`, `--muted`, `--line`, `--accent`) — text, links, rules.
- *Figure layer* (`--fig-decision`, `--fig-process`, `--fig-branch`,
  `--fig-aside`, `--fig-output`) — **only ever inside a figure.** Yellow behind
  body text is unreadable; that's why the two layers exist.

Each figure colour has a matching ink (`--fig-process-ink` and so on). Use the
pair — never black on yellow or on pink.

**Fivi speaks in her own block:**

```markdown
::: fivi
**Fivi:** something short and in character.
:::
```

## Figure widths

The reading column is deliberately narrow. Wide figures break out of it:

| Figure                                   | Class            |
|------------------------------------------|------------------|
| Small diagrams, virion anatomy           | *(default)*      |
| Classification cards, gene-content matrix| `.column-body-outset` |
| The decision tree, the body heatmap      | `.column-page`   |
| Fivi's asides, side notes                | `.column-margin` |

```markdown
::: {.column-page}
![The decision tree](../assets/img/decision-tree.svg)
:::
```

## Language

English is the source of truth. Other languages will live in subfolders
(`/es/`, `/pt/`) so that English URLs never change.

**Figure labels stay in English in every language.** `capsid`, `dsDNA` and
`prophage` are the vocabulary readers will meet in the papers and in the tools,
so translating them would not help. Only the prose gets translated — which also
means a translated chapter is a text file, not a redrawn figure.
